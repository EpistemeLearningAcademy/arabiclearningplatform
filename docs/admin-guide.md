# Admin guide

Open **Settings → 🛠 Admin** (also on the learner-selection screen). Everything is stored **on this device only**.

| Section | What it does |
|---|---|
| Admin PIN | A 4–8 digit PIN that also protects the Parent & teacher centre. It keeps children out; it is **not strong security**. |
| Certificate and branding | Organisation name, signatory name and title, certificate statement and footer (English and Arabic), and the logo, signature and stamp images. Preview shows a sample certificate. |
| Activities learners can see | Hide or show Reading library, Sentence builder, Listening lab, Writing studio. |
| Vocabulary pictures | Choose a real photo for each word from your phone, or check which pictures exist in the repository. |
| Audio | See how many items have recorded audio; check which audio files exist and copy a ready manifest. |
| Content check | Validates all lessons, passages, prompts, certificates and challenges. |
| Data | Back up all learners to one file; restore a backup (restored learners are added as new learners); download the certificate register (CSV). |

## Certificates and ELA
The certificate text and images are whatever you set here. The app cannot prove who earned a certificate: its **serial number** (e.g. KAL-0WOJ0G9) is only a code derived from the learner, certificate and date. Keep the **certificate register (CSV)** so ELA can match a printed certificate to its own records. Anyone who can edit a backup file can change progress, so do not treat certificates as proof of attainment without ELA's own checks.

## Sharing settings across devices
Settings, branding images and photos chosen in Admin stay on that device. To use them everywhere, put files in the repository (see `assets/branding/README.md`, `assets/images/vocab/README.md`, `assets/audio/README.md`) and edit `content/shared/branding.json`.
