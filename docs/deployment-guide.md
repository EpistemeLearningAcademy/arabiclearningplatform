# Deploy to GitHub Pages
1. Upload all files in this folder to the repository root (keep the folder structure).
2. Repository Settings -> Pages -> Source: "Deploy from a branch" -> Branch: main, folder: / (root) -> Save.
3. Wait about a minute; open `https://<user>.github.io/<repo>/`.
All paths are relative, so project-repo URLs work. Service workers need HTTPS (GitHub Pages provides it) or localhost.
